# 写作现场 · 界面设计

打开像 Pages：中间一张适合写作的纸，主体在纸上；AI、草稿、资料、求证这些临时内容围在周围。纸和卡跟系统浅 / 深外观走（暖稿纸 / 柔和炭纸），不是永远纯白，也不是 OLED 纯黑。不是 Mosaic 房间，不是无限画布，也不是左栏编辑器 + 右栏检查器。颜色在工程的 `WriteFieldTheme`。

iPad 横是主现场。纸上 vs 周围见 `一次写作.html` 开篇。

Soundtrack【已定】：整 app 一首，pill 在 chrome，换 Topic 不换歌。

## 后续可借：卡片材质

参考片：`card-design.mp4`（别的产品，周历，不是写作工具）。

可借：半透明玻璃卡、按类型染色、一段多张时先叠成一摞、点开再散开。系统用 SwiftUI `glassEffect`，不要自做一层模糊顶掉 Liquid Glass。

不进这一轮板。S1 的卡先能点、能跟段落 Y；材质后做。

参考：`ai-orb.mp4`（玻璃球、可分可合、内部虹彩）；Apple Intelligence Glow（角向渐变绕边）。

进行中的光只包**正在长出来的卡**或侧边端口上的球。落地后熄灭，卡走 §3.8 的玻璃。
