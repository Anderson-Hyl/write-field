### AI UX（S6 向；先 HTML，逻辑见 AI 语义面 §九 / §2.5）

仍围绕四处入口组织，以下为本轮 HTML 提案；旧三模式策略仍保留在 AI 语义面 §九，替代意见见 §9.7 / §9.8：

| 层 | 在哪 | 放什么 |
| --- | --- | --- |
| **A 纸侧边** | 当前段把手 + **召唤球**；增加点按等价 | 拉线三落点保留；点按提问不必先拖线；开题讨论明确属于本篇 |
| **B 卡菜单** | 已展开旁注 | 连续追问、选择采用、看来源；参考页放大阅读 / 剪取 |
| **C 写作意图** | Topic 级可选文字 | 作者明确保存才应用；不强迫填表，不将模型建议自动写成意图 |
| **D 命令目录 / 提问处** | ⌘K / jump 与本次请求 | 当前段、所选章节、全文；范围跟本次问题走；旧请求保留版本 |

**召唤球【待定方向，2026-09-19】**：拖线不立刻进模型；拖线路径只有松手到球上才进 AI。点按提问与键盘激活是等价入口；连续追问在讨论卡内完成。球停在边距、默认可拖、安静；靠近/请求中才亮。交互板：`ai-召唤球.html`。

**边距指针【待定方向】**：Hover 额外披露；作者旁注有明确编辑按钮，双击仍可快捷编辑。助手原始答复与作者旁注分清，不通过就地覆盖让助手内容变成作者意见。拖挪保留位移阈值；本轮修正了按下旁注后拖动状态未进入移动处理的断点。召唤球质感仍为占位。

画板顺序：

7. **入口地图** · `ai-入口地图.html` — A/B/C/D 总图，可点高亮  
8. **回填选择** · `回填选择.html` — 区分无来源候选与资料；真实选区、插入预览、脚注、撤销；手写后不覆盖新编辑  
9. **参考页卡** · `参考页卡.html` — 模拟页面、键盘选取、放大阅读、剪取；模拟刷新不声称联网成功  
10. **上下文与姿态** · `ai-上下文与姿态.html` — 单篇 Mosaic 材料、本次阅读范围、当前版本与历史快照；取代旧板的模式维护演示  
11. **召唤球** · `ai-召唤球.html` — 拖线三落点；球可拖；安静 vs 吸附 vs 进行中  
12. 扩 `ai-进行中.html` — 提问目录含 btw / 查阅  

此前阶段只改 Design HTML + 规划文档。当前已进入编码准备；实现按[可编码实现规格](写作现场%20·%20可编码实现规格%20v0.1.md)的 M0→M4 顺序推进，S5 通过前不接真实 AI。

## 后续可借：卡片材质

参考片：`card-design.mp4`（别的产品，周历，不是写作工具）。

可借：半透明玻璃卡、按类型染色、一段多张时先叠成一摞、点开再散开。系统用 SwiftUI `glassEffect`，不要自做一层模糊顶掉 Liquid Glass。

不要借：日历格子、在空白里自由抛卡片、把整张纸做成玻璃。纸是不透明的稿；玻璃只给周围的临时内容。

不进这一轮板。S1 的卡先能点、能跟段落 Y；材质后做。

## 后续：AI 进行中

参考：`ai-orb.mp4`（玻璃球、可分可合、内部虹彩）；Apple Intelligence Glow（角向渐变绕边）。

进行中的光只包**正在长出来的卡**或侧边端口上的球。落地后熄灭，卡走 §3.8 的玻璃。

**禁止**给正文 / 选区 / 整张纸套 Glow——那是 Writing Tools 改正文的样子。召唤球可安静停在边距（见 `ai-召唤球.html`），不要稿心狂转吉祥物。Reduce Motion 则进行中直接出卡。

跟 S6 一起做，不进 S1。结构见 `ai-进行中.html`、`ai-召唤球.html`。参考片：`ai-orb.mp4`。

仍未确认的视觉材料先在 HTML 里试；已经通过试看并进入实现规格的部分可按 M0→M4 落到 Swift。不要为了玻璃、卡片堆或动画越过当前 spike。
