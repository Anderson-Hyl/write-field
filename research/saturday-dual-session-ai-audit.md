## 补记（作者反馈，2026-09-19）

1. **Hoogle → 旁挂 Web**：采纳为**锚定参考页卡**（不是 Mosaic 自由 Web tile）。活页可看；进引用/AI 窗须再剪成资料卡。双滚动与研究白板风险写入异议。  
2. **AI 回填交给用户**：插入 / footnote / 留旁 / 自改 / 废弃 / 部分采用 / 钉策展——模型不代选（AI 语义面 §2.5）。  
3. **同批补充**：选区开参考页；参考页只对已剪片段提问；snippet 预览；打开页不偷焦点；无网失败态；参考页用「资料」角色色。  
4. **参考页可刷新**：作者手势重载当前页（`reference.reload`）；非定时器；刷新不自动把新 DOM 推进模型。
